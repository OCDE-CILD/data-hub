Methodology & Notes

Every dashboard on the OCDE Data Hub is built from data files published by the California Department of Education. Before those files reach a dashboard, OCDE's Research, Evaluation, and Data Insights (REDI) team cleans, standardizes, and validates them so that figures are comparable across districts, schools, and years. This page documents the rules and conventions used across that process, along with detailed notes on how each individual dataset is handled. Click on any topic below to expand its notes.

General Data Handling

A few conventions apply across every file on this site, regardless of topic:

  • Suppression. To protect student privacy, data for student groups with fewer than 11 students is suppressed and will appear blank or unavailable, consistent with California Department of Education reporting standards. In the original CDE source files, suppressed values are marked in a few different ways depending on the file and year (most often an asterisk, but sometimes a blank or "NA" value) — these are standardized before being used to build a dashboard.
  • Demographic groups. Student group and demographic labels are mapped to a single, canonical set of categories used across every file on this site, so a group like "English Learner" or "Foster Youth" means the same thing whether you're looking at attendance, academics, or another dashboard.
  • Reporting level. Every file distinguishes state, county, district, and school-level records using a consistent set of codes, so the same file can support comparisons at any of those levels.
  • School and district codes. Location codes are standardized to a fixed format across files. Where the same numeric code happens to be used at both the school and district level — an occasional artifact of how CDE issues codes — the conflict is identified and resolved so figures aren't crossed between levels.
  • Charter and alternative-school status. Charter status (yes/no/ all schools) and, where applicable, alternative accountability status (DASS) are standardized so that traditional and non-traditional schools can be reported on separately.

Attendance & Engagement

Chronic Absenteeism

Chronic absenteeism counts, rates, and enrollment figures are checked field by field for suppressed values, which are flagged and set aside before the remaining figures are converted to usable numeric values for analysis.

Companion File

A companion file breaks absenteeism down by reason (for example, excused vs. unexcused absence). It's cleaned using the same suppression and demographic group rules as the main chronic absenteeism figures, and separately identifies schools operating under alternative accountability (DASS) status. Nonpublic, Nonsectarian Schools are excluded from school-level reporting in this file.

Coverage

This process has been applied consistently to every year from 2018-19 through 2024-25, with one exception: no chronic absenteeism data is available for 2019-20, as CDE did not publish this file for the pandemic year.

Suspension

Suspension counts, rates, and enrollment figures go through the same cleaning approach as Chronic Absenteeism: suppressed values are detected and flagged, demographic groups are mapped to the site's canonical set of labels, and school/district codes are standardized and checked for conflicts.

Coverage

This process has been applied consistently across every available year, 2018-19 through 2023-24. Unlike Chronic Absenteeism, 2019-20 suspension data is available and was published by CDE for that year.

Graduation & Dropout Rate

Graduation and dropout figures reflect CDE's official four-year and five-year cohort methodology. As with the other Attendance & Engagement files, suppressed values are detected and flagged, and school/district codes are standardized.

Charter & DASS Reporting

Rates are reported separately for charter and non-charter schools, and separately identify schools operating under alternative accountability status (DASS), so traditional and alternative-school outcomes aren't blended together.

Gender Categories

CDE introduced a "Non-Binary" gender category starting in 2019-20. Because that category did not exist in 2018-19, records from that year that would otherwise fall into it are coded as missing for gender rather than being assumed or reassigned to another category.

Coverage

Methodology has remained consistent from 2018-19 through 2022-23. The 2023-24 file uses an almost identical process, with only minor field-naming differences that do not affect the calculated rates themselves.

Student Academics

Math & ELA Assessment (CAASPP)

Math and ELA results come from the CAASPP (Smarter Balanced) assessments. Achievement levels are standardized to a four-level scale: Not Met (1), Nearly Met (2), Met (3), and Exceeded (4).

2018-19 Limitations

The 2018-19 file contains percentages only — underlying student counts were not published that year. Percentage figures from 2018-19 should not be used to back-calculate a count of students (multiplying a percentage by the number of students tested does not reproduce the correct count).

Reading the Numbers

Percentages are stored as decimal proportions in the downloadable data (for example, 68.7% is stored as 0.687). A blank average scale score on the "all grades" summary row is expected by design and is not a sign of suppression; scale scores are suppressed individually only for specific grades or groups with small enrollment.

Science Assessment (CAST)

The California Science Test (CAST) reports two types of results: an overall "Core" result, and three "Area" results (Life Sciences, Physical Sciences, and Earth & Space Sciences). Core achievement levels use the same four-level scale as Math/ELA (Not Met, Nearly Met, Met, Exceeded), while Area results use a separate three-level scale (Below, Near, Above). Unlike Math/ELA, CAST does not report a combined Core + Area composite score.

Pandemic-Era Gaps

No CAST data is available for 2019-20. 2020-21 data is available but limited in quality — not all districts participated that year — so year-over-year comparisons involving 2020-21 should be made with caution.

2023-24 Changes

Starting in 2023-24, CAST files began including student counts alongside percentages, and suppression logic became more detailed. Enrollment, testing, and Area-test results can each be suppressed independently of one another — for example, it's possible for enrollment figures to be visible while related test results are suppressed, or for Area-test results to be suppressed even when Area enrollment is not.
